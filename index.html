Put Verse of the Day on a TV

This kit packages the live GitHub Pages PWA (sgeorge83.github.io/bible-daily-pwa) for a USB stick and for Android TV / Fire TV. Copy the drop-in PWA files into the existing repo, then pick a launch path.

USB launcher

Copy usb/launch.html to the root of a FAT32 flash drive. Open it from a computer on HDMI, or any browser that can read USB files. Online, it sends the display to GitHub Pages. Offline, it stays on a full-screen fallback until Wi-Fi returns.

Most Android TV file managers will not run HTML. Use the APK path for a native TV app.

Android TV APK

Package the live PWA URL with PWABuilder or Bubblewrap, lock landscape and fullscreen, copy VerseOfTheDay.apk onto the same stick, and sideload it from the TV’s file manager.

Step-by-step after the PWA files are live: docs/ANDROID-TV-APK.md.

Copy into the GitHub Pages repo

  1. Copy pwa/manifest.json over manifest.json.
  2. Copy pwa/sw.js and pwa/sw-register.js into the repo root.
  3. In index.html, add this before </body>: 
    <script src="./sw-register.js" defer></script>
  4. Push to main so GitHub Pages publishes the service worker.
  5. Then generate the APK from the live URL. See docs/ANDROID-TV-APK.md.
