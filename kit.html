Open the verse display USB splash APK guide

Put it on GitHub

Create an empty repo named tv-pwa-kit at github.com, then drag these folders and files into Add file → Upload files. Skip node_modules. Steps are in docs/GITHUB-UPLOAD.md.

USB and Android TV

Copy usb/launch.html to a FAT32 stick. Package https://sgeorge83.github.io/tv-pwa-kit/ with PWABuilder for a sideload APK. Details in the APK guide.

What this repo is

  1. The verse PWA at the site root (index.html, service worker, manifest).
  2. USB launcher in usb/.
  3. Android TV APK instructions in docs/.
